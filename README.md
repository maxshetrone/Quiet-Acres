# Description
Quiet Acres is a farming RPG where you grow crops, raise animals, and complete quests. Farm, fish, craft, and upgrade, do whatever you want.

This is mostly a vibe-coded game with not much purpose. There is probably a lot of bugs and errors. I will add as many features as I can. The code is very messy.

Thanks for playing!

# Quick Notes
You can download and change this code as much as you want. But if you post it to anyone please give me credit.

To build the `.exe`:
python -m PyInstaller main.py
