Quiet Acres is a farming RPG where you grow crops, raise animals, and complete quests. Farm, fish, craft, and upgrade, do whatever you want.

This is mostly a vibe-coded game with not much purpose. There is probably a lot of bugs and errors. I will add as many features as I can. 

Thanks for playing!
